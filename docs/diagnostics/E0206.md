# E0206 — TYPE MISMATCH

A branch of a conditional expression has the wrong type.

Both branches of `if … then … else …` must yield a common type (arithmetic promotion, or matching references). When the `if` is used as a known type — an assignment destination, a procedure argument, a boolean condition — the report names that type and the branch that does not match. `integer x; x := if true then 1 else true` means the `else` branch should be integer.
